# learn-ios

Android to iOS learning course with 148 lessons, complete app projects, quizzes and an interview ledger.

Open `course/index.html` locally and choose **Complete course** to follow the beginner-to-advanced sequence. See [setup and verification](course/README.md) for browser access, learning habits, companions and evidence limits.

Previously published site: https://manjulkadyan.github.io/learn-ios/. The 148-lesson expansion is available in this local checkout; it has not been pushed or published.
